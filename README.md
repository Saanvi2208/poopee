# poopee
Poopee is a real-time public toilet and sanitation platform that combines:
1. A public toilet discovery and reporting system for citizens/users.
2. A sanitation employment marketplace connecting sanitation workers/job seekers with cleaning and maintenance jobs.
3. A real-time "Sanitation Trust Index" for every toilet.
4. A reporting system where users can upload images of dirty/damaged toilets and request cleaning/maintenance.
5. A system where sanitation workers can accept jobs, complete them, upload proof of cleaning, and receive ratings.
6. A map showing the user's nearest public toilets and their current condition.
